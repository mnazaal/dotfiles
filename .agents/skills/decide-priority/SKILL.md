# Skill: Decide Priority

## Rules

- Parking is not deciding. State what would bring the work back, in the user's
  words. A parked item with no revisit trigger is an abandoned one that still
  looks alive.
- Keep the user's names for the options. Scoring-table row labels must be
  meaningful alone — never `P0`, `Option A`, or a letter.

## Related Skills

- `research-session` for research idea decisions (pursue/refine/park/kill).
- `debug-root-cause` when the uncertainty is an unknown root cause, not a
  choice between known options.
