# Skill: Context Org

## Rules

- Follow host/global storage policy. If unclear, ask where to write.
- Preserve provenance: source path/URL, date, summary, tags, related links, next action.
- Never write into personal note stores unless policy or user explicitly allows it.
- Prefer Org headings/properties/tags for Org artifacts.

## Workflow

1. Identify target store and permissions.
2. Normalize content with provenance.
3. Choose heading/file shape that matches existing notes.
4. Write only requested/allowed artifacts.
5. Report path and next action.
